1 Запуск сервера.
Пишем в терминал:
cd cloud_server 
python main.py


2 Запуск туннеля.
Открыть новый терминал и написать в него:
ssh -o ServerAliveInterval=60 -R 80:127.0.0.1:8765 nokey@localhost.run
делать только на компе Dvarren'а. вам не нужно, это только для меня, я хост

3 Обновление ссылки.
При запуске облака в открытом проводнике нужно поменять URL ссылку на ту, что выпишет терминал туннеля.
